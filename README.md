Superstore Sales Analysis | SQL · Python · Power BI

An end-to-end data analysis project on a US retail (Superstore) sales dataset. It covers about 9.8K order lines (4.9K orders, 793 customers, 1,861 products) across 4 regions, 49 states, 3 product categories and 3 customer segments, from 2015 to 2018. The goal is to turn raw transactional data into insights that explain what drives revenue, where the business is strong or weak, and what sales may look like next.

Project idea, in simple terms:
A retail store records every sale, but raw rows don’t tell a story. This project cleans that data, explores it, and answers practical business questions:

How have sales changed over time, and are there seasonal patterns?
Which regions, states and cities perform best?
Which categories, sub-categories and products bring in the most revenue?
Which customer segments and top customers matter most?
Which shipping modes are used the most?
What are expected sales for the coming period?

Workflow:

SQL (data cleaning): Remove duplicates and handle missing values. Fix data types and date formats. Standardize text fields, and create a clean, consistent table ready for analysis.
Python (preprocessing, analysis and forecasting): Use Pandas and NumPy for preprocessing and feature engineering (year, quarter, month, shipping time). Run exploratory analysis with Matplotlib and Seaborn to find trends, outliers and patterns. Build a time-series forecasting model, for example Prophet or ARIMA, to predict future sales.
Power BI (visualization): Build an interactive dashboard with KPIs (total sales, orders, customers, quantity). It includes trend lines, region and state maps, category and segment breakdowns, and slicers for year, region and category, so decision-makers can explore the results themselves.

Outcome: A clear picture of past performance, the key growth drivers, and a sales forecast that supports decisions on inventory, targeting and regional strategy.

Tools: SQL Server · Python (Pandas, NumPy, Matplotlib, Seaborn, Prophet/Statsmodels) · Power BI
